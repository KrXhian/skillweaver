Built for Humans & LLMs Alike

Structured Block Editor + Raw Mode

Collapsible #–### sections, Shift+Tab outdenting, 9 semantic colors, Prism code blocks, resizable GFM tables, pasted images, and instant toggle to raw .md.

Side & Fullscreen Weighted Knowledge Graph

Explore the local relationship network side-docked (Ctrl+G) or edge-to-edge fullscreen (Ctrl+Shift+G): repeated citations increase edge weights (×N), collapse reciprocal ties into single <---> or ---> strength-colored arrows (green/blue/slate), mute unrelated hops around the active page, support 1-click AI cluster loading, and reset cleanly via R.

Multi-Key BYOK AI & SKILL.md Bank

Keep multiple keys across OpenAI, Google Gemini, Anthropic, OpenRouter, Ollama, and custom endpoints encrypted via Windows DPAPI. Switch models in one click and reuse portable @skill prompts.

Live Hot-Reload & Conflict Diff

Debounced Rust filesystem watcher syncs changes made by external agents or Git into open notes smoothly — and guards unsaved edits with a non-blocking diff resolver.

Folder Explorer & Templates

Browse folders as structured overviews with .skillweaver/frontmatter.yml metadata and reusable templates supporting {{title}} and {{date}} placeholders.

Collapsible Left Outline & Token Bar

Navigate headings two-way from a distraction-free left outline drawer (Ctrl+Shift+O) while monitoring live words, characters, and BPE-aware LLM ~tokens.

Frequently Asked Questions

What is Skillweaver desktop Markdown editor?

Skillweaver is a local-first Windows desktop Markdown editor built with Rust and Tauri v2 by the Blue Frog Foundation. It stores notes purely as plain .md files inside regular folders while providing structured block editing, side-docked and fullscreen citation-weighted knowledge graphs, multi-key BYOK AI, reusable SKILL.md workflows, an integrated terminal, and a zero-dependency stdio MCP server.

How is Skillweaver different from Obsidian and Notion?

Unlike Notion, all Skillweaver notes live locally in plain Markdown folders with zero cloud lock-in. Unlike Obsidian, Skillweaver includes structured blocks, outdenting, a citation-weighted local relationship graph with strength-coded bidirectional arrows, multi-provider BYOK AI, live token telemetry, portable SKILL.md workflows, and an MCP server natively out of the box without plugin soup or Electron memory overhead.

Can external AI agents connect to Skillweaver vaults via MCP?

Yes. Running skillweaver.exe --mcp starts a zero-dependency stdio MCP server exposing list_notes, read_note, search_vault, resolve_block, get_vault_graph (with node metadata and edge citation weights), create_note, and append_to_note. File changes made by agents hot-reload live into open notes with safe conflict detection.

How does Skillweaver's citation-weighted knowledge graph work?

Repeated [[wikilink]] citations between notes increase each edge's citation weight, pulling closely cited topics tighter together and boosting 1-hop relevance. Reciprocal links collapse into a single bidirectional arrow (<--->) while one-way links stay single arrows (--->), color-coded emerald green for strong ties, blue for medium ties, and slate for passing mentions, with hop-based calm fading around the active page and instant reset via R.
